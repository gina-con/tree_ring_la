amongdev_betula: code for Betula pendula generalised linear mixed effect models, AIC multi-model comparison and model figure generation.
amongdev_fagus: code for Fagus sylvatica generalised linear mixed effect models, AIC multi-model comparison and model figure generation.
amongdev_quercus: code for Quercus petraea generalised linear mixed effect models, AIC multi-model comparison and model figure generation.
data_loading: code to extract relevant data from the GenTree Dendroecological Collection and E-OBS dataset. 
model_spline: code to trial fitting a spline to centred year to capture age effects, prior to inclusion into main model, to validate as an approach for capturing age trends. 
supplementary_figures: code to generate figures for the appendix of the report such as additional climate trend graphs and confidence interval plots.
